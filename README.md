# MangoJelly Landing Page

A responsive and animated landing page inspired by the official MangoJelly website, built using HTML, CSS, and JavaScript. The project focuses on creating smooth user interactions, modern UI aesthetics, and engaging animations powered by GSAP.

---

## 🚀 Features

- Fully responsive design
- Smooth GSAP-powered animations
- Modern and clean landing page UI
- Interactive navigation experience
- Optimized layout structure
- Mobile-friendly interface
- Organized and maintainable codebase

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)
